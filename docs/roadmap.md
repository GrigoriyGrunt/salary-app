# Принятые решения

- Сначала реализуется функциональность.
- Затем выполняется полировка интерфейса.
- Работа ведётся по одному небольшому шагу.
- Архитектура проекта не меняется без обсуждения.
- Компоненты должны быть максимально переиспользуемыми.
- Все новые экраны строятся на основе существующего UI Kit.
- Главный экран считается завершённым после адаптивности и Pixel Perfect.
- После завершения Главного экрана начинается разработка экрана **«Расчёт зарплаты»**.
